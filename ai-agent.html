✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · 大模型基础

入门 ⏱ 3-4 周

理解大语言模型的能力边界与基本原理，学会通过 API 调用模型。

LLM 基本原理 Tokenizer / Token API 调用 上下文窗口 模型选型 Python 基础
2

第二阶段 · Prompt 工程

进阶 ⏱ 3-4 周

掌握与模型高效沟通的技巧，让输出更稳定、可控、结构化。

Prompt 结构 Few-shot Chain of Thought 角色设定 结构化输出 Prompt 测评
3

第三阶段 · RAG 检索增强

必备 ⏱ 1-2 个月

让模型接入私有知识，理解文档切分、向量检索与重排序全流程。

文档切分 Embedding 模型 向量数据库 相似度检索 Rerank 评测召回质量
4

第四阶段 · 工具调用与智能体

高级 ⏱ 1-2 个月

构建具备规划、记忆与工具使用能力的 Agent，掌握主流框架。

Function Calling Agent 循环 LangChain / LlamaIndex 记忆机制 工具设计 ReAct 模式
5

第五阶段 · 多智能体与工程化

架构 ⏱ 持续

从单体 Agent 到多智能体协作，并完成可观测、可评估的生产化落地。

Multi-Agent 协作 工作流编排 任务分解 效果评估 可观测性 安全与护栏
