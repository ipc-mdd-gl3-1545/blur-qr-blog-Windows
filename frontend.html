✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · 基础三剑客

入门 ⏱ 1-2 个月

打好地基，理解 Web 运行本质。重点是语义化标签、盒模型、布局体系与 JS 核心语法。

HTML 语义化 CSS 盒模型 Flex / Grid 布局 JavaScript 基础 DOM 与事件 ES6+ 语法
2

第二阶段 · 现代框架

进阶 ⏱ 2-3 个月

掌握组件化思想与主流框架，理解响应式数据、虚拟 DOM 与状态管理。

React / Vue 组件化开发 状态管理 路由 TypeScript Hooks / Composition API
3

第三阶段 · 工程化

必备 ⏱ 1-2 个月

从写代码到交付项目，掌握构建工具、规范体系与协作流程。

Vite / Webpack 包管理 npm/pnpm Git 与协作 ESLint / Prettier 单元测试 CI/CD 基础
4

第四阶段 · 深入原理

高级 ⏱ 持续

深入浏览器与框架底层，形成可迁移的技术判断力。

浏览器渲染原理 事件循环 框架源码 性能优化 网络协议 手写轮子
5

第五阶段 · 拓展方向

拓展 ⏱ 按需

根据兴趣向纵深或横向发展，形成个人技术标签。

SSR / SSG Node.js 全栈 跨端 / 小程序 可视化 / Canvas WebGL 微前端
