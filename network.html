计算机网络 学习地图

沿着数据包的旅程，从 OSI/TCP-IP 模型到 HTTP/HTTPS，从网络安全到性能调优，建立完整的网络知识体系。

TCP/IP HTTP/HTTPS DNS 网络安全 抓包分析 性能优化
✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · 网络基础模型

入门 ⏱ 1-2 个月

理解网络分层思想与各层职责，弄清数据如何封装与传输。

OSI 七层模型 TCP/IP 四层 IP 地址与子网 MAC 地址 ARP 协议 数据封装过程
2

第二阶段 · 核心协议

进阶 ⏱ 2 个月

吃透传输层与应用层关键协议，理解连接的建立与可靠性保障。

TCP 三次握手/四次挥手 UDP 流量控制 拥塞控制 DNS 解析 ICMP / NAT
3

第三阶段 · HTTP 与 Web

必备 ⏱ 1-2 个月

掌握 Web 通信细节，理解状态码、缓存机制与 HTTPS 加密原理。

HTTP 方法/状态码 请求响应报文 Cookie / Session HTTP 缓存 HTTPS / TLS HTTP2 / HTTP3
4

第四阶段 · 网络安全

高级 ⏱ 1-2 个月

了解常见攻击手段与防御机制，建立安全思维。

对称/非对称加密 数字证书 防火墙 VPN 常见 Web 攻击 DDoS 防护
5

第五阶段 · 实战与调优

实战 ⏱ 持续

学会用工具分析网络问题，从实操中深化理论理解。

Wireshark 抓包 tcpdump 网络编程 Socket CDN 原理 延迟与吞吐优化 负载均衡
