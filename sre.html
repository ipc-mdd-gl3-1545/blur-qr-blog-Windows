✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · 系统基础

入门 ⏱ 1-2 个月

扎实的 Linux 与网络功底是运维的根基，学会用脚本自动化重复工作。

Linux 常用命令 Shell 脚本 TCP/IP 网络 DNS / HTTP 进程与资源 Vim / Git
2

第二阶段 · 服务与部署

进阶 ⏱ 2 个月

掌握常见服务搭建与自动化部署流程，理解配置管理与持续交付。

Nginx Ansible Jenkins / GitLab CI 灰度发布 负载均衡 日志管理
3

第三阶段 · 容器与编排

必备 ⏱ 2-3 个月

云原生核心能力，从镜像构建到大规模集群编排与治理。

Docker Kubernetes Helm Service Mesh Operator K8s 调度原理
4

第四阶段 · 可观测性

高级 ⏱ 2 个月

建立指标、日志、链路三位一体的观测体系，做到问题可发现、可定位。

Prometheus Grafana ELK / Loki 链路追踪 告警治理 SLO / SLI
5

第五阶段 · 稳定性建设

架构 ⏱ 持续

从救火到防火，用工程手段系统性提升服务可靠性。

故障排查 混沌工程 容量规划 应急预案 根因分析 RCA FinOps 成本优化
