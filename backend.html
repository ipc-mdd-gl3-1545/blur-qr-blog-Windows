后端开发 学习地图

从一门服务端语言出发，深入数据库、缓存、消息队列与分布式架构，打造高可用的后端系统能力。

Java / Go 数据库 Redis 消息队列 微服务 分布式
✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · 语言与基础

入门 ⏱ 2 个月

选择一门主力语言（Java/Go/Python），吃透语法、数据结构与面向对象思想。

Java / Go 基础 数据结构与算法 面向对象 并发基础 Linux 基础 Git
2

第二阶段 · 数据与存储

进阶 ⏱ 2 个月

理解关系型数据库原理与 SQL，学会用缓存提升系统性能。

MySQL SQL 与索引 事务与锁 Redis 数据建模 慢查询优化
3

第三阶段 · 框架与开发

必备 ⏱ 2 个月

熟练使用主流框架，理解 MVC、依赖注入与接口设计规范。

Spring Boot / Gin RESTful API ORM 框架 认证鉴权 接口文档 参数校验
4

第四阶段 · 中间件

高级 ⏱ 2-3 个月

掌握解耦、削峰与异步能力，理解高并发场景下的组件协作。

消息队列 Kafka/RabbitMQ 分布式锁 搜索引擎 ES 分库分表 CDN 对象存储
5

第五阶段 · 架构与分布式

架构 ⏱ 持续

建立系统设计能力，理解微服务治理与稳定性保障。

微服务 / Spring Cloud 服务注册发现 负载均衡 分布式事务 限流熔断 容器化部署
