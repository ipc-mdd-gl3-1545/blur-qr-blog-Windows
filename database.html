数据库 学习地图

SQL MySQL 索引 / 事务 存储引擎 Redis 分布式数据库
✦ Learning Path

分阶段 学习路线

由浅入深，循序渐进。每个阶段给出核心知识点，按路线推进即可建立完整体系。

1

第一阶段 · SQL 与关系模型

入门 ⏱ 1-2 个月

理解关系型数据库的核心概念，熟练编写 SQL 是数据开发的地基。

关系模型 SQL 增删改查 多表 JOIN 聚合分组 子查询 数据库设计范式
2

第二阶段 · 深入 MySQL

进阶 ⏱ 2 个月

掌握索引原理、事务隔离与锁机制，学会诊断和优化慢查询。

B+树索引 事务 ACID 隔离级别 MVCC 行锁 / 表锁 EXPLAIN 分析
3

第三阶段 · 存储引擎与架构

高级 ⏱ 1-2 个月

理解数据如何落盘与复制，掌握高可用架构与备份恢复方案。

InnoDB 存储引擎 Buffer Pool redo / undo log 主从复制 读写分离 备份与恢复
4

第四阶段 · NoSQL 与缓存

拓展 ⏱ 1-2 个月

根据场景选择合适的存储：缓存、文档、列式、图数据库各有所长。

Redis 数据结构 缓存穿透/击穿/雪崩 MongoDB Elasticsearch 时序数据库 持久化策略
5

第五阶段 · 分布式数据库

架构 ⏱ 持续

面对海量数据与高并发，理解分库分表、分布式事务与一致性协议。

分库分表 分布式事务 CAP / BASE 一致性哈希 NewSQL(TiDB) 数据迁移方案
